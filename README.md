# 银盐图书馆 · Silvergrain Library

<img src="src/assets/silvergrain-app-icon.png" alt="银盐图书馆应用图标" width="128" />

为胶片摄影、暗房冲洗和摄影器材资料设计的 Windows 离线图书馆。

**Design by ELEVANFILM**

把散落的胶片技术数据表、冲洗工艺说明、相机与镜头手册集中整理，以品牌、材料、工艺和资料类型浏览；点击首页预览，即可在应用内阅读完整 PDF。

当前版本：`0.1.0`。截至 2026 年 11 月 11 日，完整资料版收录 **694 份 PDF**。目前提供 Windows 桌面版，macOS、Android 和 iOS 版本尚未发布。

## 功能

- **分类浏览**：全部资料、技术文档、冲洗工艺、感光材料、相机资料和其他。
- **PDF 首页预览**：品牌首页展示最多三份代表资料，进入品牌后可展开分组浏览完整列表。
- **资料查找**：在当前栏目搜索名称、文件名、品牌、分类等信息；在“全部资料”中搜索全部栏目。原出版编号可用于查找已重新命名的资料。
- **完整 PDF 阅读**：采用 Chromium 内置 PDF 阅读器，支持翻页、缩放、选中文字复制、文内查找及导出。
- **中英文界面**：导航、分类、品牌和资料显示名称随界面语言切换，PDF 原文保持原有语言。
- **页面位置记忆**：在一次运行中保留各页面的滚动位置、品牌子页和分组展开状态，返回页面时恢复。
- **重启复位**：重新打开软件后，各页面从顶部开始，次级分组默认收起，目录树默认关闭。
- **离线使用**：完整资料版的 PDF 随安装包提供，阅读和查找无需联网。

资料列表的搜索与阅读器内的文内搜索是两个功能。当前内置资料列表按资料信息查找，不对全部内置 PDF 正文建立全文索引；阅读器可查找当前 PDF 的文字。纯图片扫描件没有文字层时，不能直接复制或查找图中文字。

## 资料分类

| 栏目 | 组织方式 | 当前内置数量 |
| --- | --- | ---: |
| 感光材料 | 品牌 → 静态摄影胶片／电影卷 → 在产／已停产／待核实 | 356 |
| 相机资料 | 品牌 → 相机资料／镜头资料／维修手册／滤镜／其他配件 | 147 |
| 冲洗工艺 | B&W → C41 → E6 → ECN-2 → 放大彩扩 → 其他 | 143 |
| 技术文档 | 暗房设备、电影制作、感光材料与影像、行业标准与规范等主题 | 48 |
| 全部资料 | 汇总全部栏目，提供跨分类查找 | 694 |
| 其他 | 收录不属于上述主题的补充资料 | 0 |

电影卷位于柯达品牌下的独立分组。无法确认生产状态的资料放入“待核实”，不直接认定为在产或停产。

整理资料时按实际正文确认主题和名称。同名文件如果内容不同，会分别保留；不同名称但实际内容完全一致的重复件会去重。不同年份、出版编号、语言和胶片规格的版本分别标注，例如：

- `柯达 D-76 显影液（J78，2002版）`
- 中文版本在名称后标注 `（中文版）`，英文界面显示 `(Chinese Edition)`。
- 同一产品的 `135`、`120` 等规格在确认后体现在名称中。

## 安装与使用

Windows 安装包名称为 `银盐图书馆 Setup 0.1.0.exe`。下载后运行，按提示选择安装目录。

完整资料版安装包约 **1.45 GB**，包含当前整理的全部 694 份 PDF。安装后从桌面或开始菜单启动“银盐图书馆”。

1. 点击左侧栏目选择资料类型。
2. 在感光材料或相机资料中点击品牌名称，再展开所需分组。
3. 点击 PDF 预览或资料名称打开阅读器。
4. 顶部搜索栏用于查找资料。需要跨栏目搜索时，先进入“全部资料”。
5. 右上角“目录”用于展开目录树；选择目标后点击“跳转”。
6. 点击左下角语言按钮切换中文和英文。

侧栏和顶部导航保持固定，主内容独立滚动。本次运行中的页面位置会保留，退出软件后清空。

### 阅读器操作

| 操作 | 使用方式 |
| --- | --- |
| 缩放 | 使用阅读器工具栏中的缩放控件 |
| 复制文字 | 选中文字后按 `Ctrl + C`，也可使用右键菜单 |
| 文内搜索 | 点击搜索框，或在阅读器内按 `Ctrl + F` |
| 下一个／上一个匹配 | `Enter`／`Shift + Enter`，或搜索框旁的箭头 |
| 导出 PDF | 点击导出按钮；阅读器获得焦点时也可按 `Ctrl + S` |
| 关闭阅读器 | 点击关闭按钮，或按 `Esc`；搜索框有关键词时先清空关键词 |

导出通过“另存为”选择目标位置。应用使用临时副本打开阅读器，资料库中的原始 PDF 保持不变。

## 本地开发

技术栈：**Electron、React、TypeScript、Vite、PDF.js**。完整阅读使用 Chromium／PDFium，资料卡片首页预览使用 PDF.js。

建议使用 **Node.js 24 LTS** 和 npm。以下命令在项目根目录执行：

```powershell
npm ci
npm run dev
```

开发命令会启动 Vite 和 Electron。不要直接用浏览器打开 `index.html`，应用依赖 Electron 提供的本地文件和阅读器接口。

### 资料文件

源码与大体积资料分开管理。仅下载源码不会自动获得完整资料库；运行完整资料版或构建带资料的安装包前，需要将资料放入项目根目录的 `film-library` 文件夹，保留目录结构和 PDF 文件名。已有完整安装版时，可将安装目录中的 `resources/film-library/` 复制到项目根目录。

```text
film-library/
├─ brands/
│  └─ 品牌/
│     ├─ 在产/*.pdf
│     ├─ 已停产/*.pdf
│     ├─ 待核实/*.pdf
│     └─ 电影卷/
│        ├─ 在产/*.pdf
│        └─ 已停产/*.pdf
├─ equipment/
│  └─ 品牌/
│     ├─ 相机资料/*.pdf
│     ├─ 镜头资料/*.pdf
│     ├─ 维修手册/*.pdf
│     ├─ 滤镜/*.pdf
│     └─ 其他配件/*.pdf
└─ industry/
   ├─ 冲洗工艺/
   │  ├─ B&W/*.pdf
   │  ├─ C41/*.pdf
   │  ├─ E6/*.pdf
   │  ├─ ECN-2/*.pdf
   │  ├─ 相纸/*.pdf
   │  └─ 其他/*.pdf
   └─ 其他主题/*.pdf
```

当前物理目录 `相纸` 在界面中显示为“放大彩扩”。中英文显示名称及经过核对的文档标题位于 `src/documentTitles.json`，原始目录仍使用上述中文名称。

### 构建

```powershell
# 编译前端并检查 TypeScript
npm run build

# 构建 Windows NSIS 安装包
npm run dist:win
```

安装包输出到 `release/`，名称为 `银盐图书馆 Setup 0.1.0.exe`。打包会包含 `film-library/brands`、`film-library/equipment` 和 `film-library/industry` 中的 PDF；构建前应确认资料已放齐。

### 回归检查

准备好资料文件并执行 `npm run build` 后，可运行：

```powershell
# 栏目、品牌、目录、搜索与中英文切换
npx electron tests/catalog-navigation.cjs

# 页面位置、展开状态、长短页面切换与重启复位
npx electron tests/page-memory.cjs
```

这些检查使用独立临时用户目录，不修改实际安装版的用户数据。测试仍需从本地资料库读取一份有效 PDF 作为预览样本。

## 项目结构

```text
electron/              Electron 主进程、IPC 和 Chromium PDF 阅读器
src/                   React 界面、资料名称映射和页面状态
src/assets/            像素风格栏目图标与应用图标
public/pdfjs/          PDF.js 预览所需的字符映射与字体资源
film-library/          PDF 资料目录，原件独立于源码管理
build/                 Windows 应用图标
tests/                 导航与页面状态回归检查
release/               本地构建产物，不提交到 Git
```

用户资料存储在 Electron 的 `userData` 目录下的 `library/` 中；内置资料在安装目录的 `resources/film-library/` 中。页面位置与展开状态仅保存在本次运行的内存中。
